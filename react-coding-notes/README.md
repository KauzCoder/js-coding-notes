# ⚛️ React Coding Notes

Trilha prática e progressiva para estudar React do zero ao deploy, com foco em projetos reais, organização e consistência.

---

## 🎯 Objetivo

- Consolidar fundamentos de React com prática diária.
- Evoluir de componentes simples para aplicações com rotas, API, estado global e testes.
- Fechar o ciclo completo: desenvolvimento, qualidade e publicação.

---

## 🗺️ Roadmap (8 semanas)

| Semana | Módulo | Foco | Entregável |
|---|---|---|---|
| 1 | [01 - Fundamentos](01-fundamentos/) | JSX, componentes, props, listas, eventos | Mini app de contador + lista simples |
| 2 | [02 - Estado e Efeitos](02-estado-e-efeitos/) | `useState`, `useEffect`, formulários controlados | Busca com loading/erro |
| 3 | [03 - Rotas](03-rotas/) | React Router, páginas e layout | Dashboard com 3 páginas |
| 4 | [04 - API e Dados](04-api-dados/) | Fetch/Axios, estados de requisição | Catálogo com filtros |
| 5 | [05 - Formulários](05-formularios/) | React Hook Form + validação | Cadastro completo |
| 6 | [06 - Estado Global](06-estado-global/) | Context API + Zustand/Redux Toolkit | Carrinho com estado global |
| 7 | [07 - Testes](07-testes/) | RTL + Vitest/Jest | Testes dos fluxos críticos |
| 8 | [08 - Deploy](08-deploy/) | Build, envs, deploy e docs | App publicado + README técnico |

Para concluir cada módulo:

- [ ] Criar um mini projeto funcional.

- [ ] Registrar próximos passos.

---

## 📌 Regras de estudo

- 70% prática e 30% teoria.
- Sempre começar por um MVP simples e evoluir por incrementos.
- Evitar pular etapas (principalmente estado, efeitos e rotas).
- Em cada projeto, pensar em: UX, organização, legibilidade e testes.
